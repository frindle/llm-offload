# What offload-repo-sync copies into this repo (one-way: live -> repo; the live files are never written).
# One entry per line; '#' starts a comment. Sections:
#   [bin-exclude]  ~/bin paths (fnmatch globs) left out of bin/: separate projects that only share the folder.
#                  Everything else committed in ~/bin (HEAD, not the working tree) is copied, symlinks excepted.
#   [git-sources]  dest|checkout|ref: that commit of another local checkout becomes <dest>/ (minus its .github/).
#   [runtime]      globs of files that machines run straight from this repo or its images. They must be free of
#                  private info BEFORE the scrub, because a scrubbed address would break them.
#   [hooks]        ~/.claude/hooks/<name>             -> hooks/
#   [launchd]      ~/Library/LaunchAgents/<name>      -> launchd/
#   [config]       ~/.ollama-dispatch/<name>          -> config/
#   [state-docs]   ~/.ollama-dispatch/<name>          -> docs/state/
#   In the last four, a name with * ? or [ must match exactly one file.
# Every file is scrubbed and scanned for secrets and private info before anything is committed.
